## Complete technical details

- [Readable PDF record](reproducibility.pdf)
- [Exact LaTeX source of the record](reproducibility-source.tex)

The record contains hardware and software environments, measured runtimes, source and checkpoint identifiers, split-construction and correction history, validation and recovery records, asset licenses, and the boundaries of the existing release. It preserves the paper's technical appendix before that material was moved online. Printed page and section numbers refer to that draft.

Code and experiment records are still being prepared for release. The historical anonymous archive linked in the record contains earlier materials but not all camera-ready follow-ups. This document does not claim that the complete reproducibility package is already available.
