# IntPhys2 extraction environment

`requirements.txt` describes the GPU extraction stack used for the corrected IntPhys2 representation package. The executed workstation used Python 3.11.7, PyTorch 2.8.0 with CUDA 12.8, and xFormers. Use the separately pinned `environments/smoke/requirements.txt` under Python 3.12.13 for archive validation and compact analyses; it does not require xFormers.
