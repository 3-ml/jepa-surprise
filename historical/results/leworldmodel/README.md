# LeWorldModel result map

- `tworoom_action_consistency/` evaluates lawful, zero, and opposite actions against identical rendered targets, plus rendered-effect-matched hue interventions.
- `pusht_action_consistency/` applies the same construction in a contact-rich task and retains rejected-candidate and block-motion diagnostics.
- `pusht_role_color/` contains the fresh 256-episode matched role-color run.
- `pusht_role_color_decomposition/` reruns the same sources while retaining predictor and target shifts for exact MSE decomposition.

All four directories use released task checkpoints and native latent MSE. The independent unit is an episode.
