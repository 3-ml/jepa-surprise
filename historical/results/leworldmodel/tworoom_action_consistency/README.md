# TwoRoom action consistency

The 256-episode confirmatory run simulates lawful targets at five displacement scales and reuses each exact target under lawful, zero, and opposite action blocks. Static-target hue rotations provide appearance controls.

`scores.csv` contains every native-MSE score and rendered-effect measurement. `same_target_contrasts.csv` gives action deltas, `construct_comparisons.csv` gives hue-versus-action comparisons, and `condition_summary.csv` aggregates conditions. The two manifest CSVs preserve deterministic selection; `provenance.json`, `environment.txt`, and `status.json` preserve the execution contract.

At full scale, zero-minus-lawful is 1.463 and opposite-minus-lawful is 1.884. Matched 120-degree and 180-degree hue interventions exceed opposite-action error by 0.222 and 0.220.
