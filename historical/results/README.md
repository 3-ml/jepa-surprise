# Result map

- `intphys2/` contains the corrected development and sealed representation study, current five-fold scene-cross-fit audit, controlled geometry, post-sealed multi-dose trajectories, and superseded probe analyses.
- `leworldmodel/` contains the controlled action and appearance experiments.
- `dinowm/` contains the confirmatory PushT controlled-displacement scorer.
- `jepa_wm/` contains the post-hoc exploratory PushT extension.
- `kubric/` contains exact-render validation and the V-JEPA2-G eight-scene pilot.
- `static_content_diagnostic/` contains the V-JEPA2-L Physion++ window audit.

Each leaf directory retains raw scores, processed tables, validation records, compact feature arrays where available, and figures used to inspect the corresponding paper result. Original project notes and unrelated experiments are excluded.
